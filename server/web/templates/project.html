Setup

Add the action to each workflow job you want to monitor. Place it before your other steps so egress capture starts from the beginning of the job. 

jobs:
  your-job:
    runs-on: ubuntu-latest
    permissions:
      id-token: write   # required — lets the action mint an OIDC token
    steps:
      - uses: actions/checkout@v7

      - uses: nicolasparada/ghapp-demo@main

      # ... your other steps ...

The id-token: write permission is required so the action can authenticate with the control-plane in the post-step. The action is fail-open and Linux-only — it is a no-op on non-Linux runners.
